# Gerador de Tabuada Interativo

Página web simples que pede um número de 1 a 10 e mostra a tabuada correspondente em uma tabela.

## Como usar

1. Abra o arquivo `index.html` no navegador ou pelo [link](https://tesma.github.io/visualizador-tabuada/).
2. Digite um número de 1 a 10 na janela que aparece.
3. Clique em **Gerar tabuada!** para ver o resultado.
4. Clique em **Nova tabuada** para escolher outro número.

Valores fora do intervalo são ajustados automaticamente (por exemplo, 15 vira 10).

## Estrutura do projeto

```
.
├── index.html   # estrutura da página e do dialog
├── script.js    # validação do número e geração da tabela
└── style.css    # estilo da página
```
